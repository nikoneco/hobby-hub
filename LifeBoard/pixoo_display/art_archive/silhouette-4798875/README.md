# First monochrome walking silhouette

Preserved on 2026-10-04 before reshaping the walking cat's neck, chest and hips.

- `walking.png`: original frame 14 at 64x64.
- `walking_sprite.js`: original walking sprite and its colour. It uses the shared
  `drawNightCatPattern` and `drawLine` helpers from the renderer.

The complete original renderer and seated scene remain in commit `4798875`:
`LifeBoard/pixoo_display/pixoo_lifeboard.js`. These files are never imported by the
live renderer. The older grey tabby remains in `../gray-tabby-cade2ab/`.
